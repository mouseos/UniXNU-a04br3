# 完了済みGPU I/Oの早期記録

`a04br3-gio=6` は既定OFF。`=4` の待機系列診断に加え、250 msごとに
既存リングの完了記録を最大2件出す。記録は周期レポートとCASで奪い合い、
いずれか一方が受け取る。時刻はmach_absolute_timeのナノ秒換算で、
PID・TID・kind・fence・結果を含む。live出力の追加分は1巡最大2件で、
各巡の前に250 ms sleepする。周期reportや他の診断出力は別にある。
同期UARTやスケジューリングにより回収間隔は保証されない。

成功かつ2 ms未満のI/Oは従来どおり集計のみ。未完了I/Oも出力されない。
追跡対象はbackboarddのWaitFenceおよびSubmitJobsのロック待ちと処理のみで、
それ以外のIOKit処理・ユーザー空間処理・スレッド停止を網羅しない。
空き枠不足は既存droppedに累積される。panic時の未出力や直前の周期報告後の
欠落を否定できない。スロット消費後・出力前のpanicもdroppedに計上されない。
競合や上限で出力順はイベントの時間順と限らない。
診断は観測対象に割込み・UART負荷を加えるため既存記録と比較する。
